# Memory Index

Project memories, stored in the repository so they reach cloud sessions.

A cloud session starts from a fresh VM with only this repo cloned — user-scope
`~/.claude/projects/*/memory/` does not travel. The `personal@progdroid` plugin's
SessionStart hook copies this directory into the path the memory subsystem reads
from, and its Stop hook copies anything new back here before committing. Editing
these files by hand is fine; they are ordinary memory files.

Two memories are deliberately **not** here: `prefer-thorough-refactor-options`
(cross-project, already carried by the plugin's `working-style` skill) and
`global-claude-config-symlink` (machine configuration, not project knowledge).
