# Actual Budget Automation (`aba`) — Phase 1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a one-shot Rust binary `aba` that fetches Monzo transactions, skips ones matching Actual schedules, normalises payees via Claude, holds unknown payees for manual review, and imports the rest into self-hosted Actual through a Node.js `@actual-app/api` shim — with a no-write `--dry-run` mode.

**Architecture:** Single async (tokio) Rust binary with focused modules (config, state, banks, actual, claude, matching, notify, run). Bank sources sit behind an async `BankSource` trait (Monzo only this phase). Actual operations go through a short-lived Node shim invoked per-op over stdin/stdout JSON. State is a TOML file on a mounted volume. Pure logic (state machine, matching, request/response building) is unit-tested; HTTP surfaces are tested with `wiremock`; the shim boundary is tested with a fake node script.

**Tech Stack:** Rust 2024, tokio, reqwest (rustls), serde/serde_json, toml, chrono, clap, async-trait, thiserror/anyhow, strsim, tiny_http + webbrowser (OAuth bootstrap), tracing. Node 22 + `@actual-app/api` (npm) for the shim. Docker multi-stage → GHCR. Dev: wiremock, tempfile.

**Reference docs the engineer should skim:**
- Spec: `docs/superpowers/specs/2026-06-01-actual-budget-automation-design.md`
- Actual API: `importTransactions(accountId, txns)` reconciles via `imported_id`; payees via `getPayees()`; schedules via `runQuery(q('schedules').select([...]))`. Pass `payee` (id) not `payee_name` to avoid auto-creating payees. Amounts are integer minor units, negative = outflow.
- Anthropic Messages API: `POST https://api.anthropic.com/v1/messages`, headers `x-api-key`, `anthropic-version: 2023-06-01`. Prompt caching is GA: add `"cache_control": {"type":"ephemeral"}` to the large/stable content block. Force structured output with a tool + `tool_choice`.
- Monzo API: OAuth2 refresh at `POST /oauth2/token`; transactions at `GET /transactions?account_id=&since=&expand[]=merchant` with `Authorization: Bearer`. Refresh **rotates** the refresh token. After first auth the user must approve in the Monzo app (SCA) or only the last 5 minutes are returned.

```rust
//! Persistent TOML state.

use std::collections::BTreeMap;
use std::path::Path;

use chrono::{DateTime, Utc};
use serde::{Deserialize, Serialize};

#[derive(Debug, Default, PartialEq, Serialize, Deserialize)]
pub struct State {
    pub last_run: Option<DateTime<Utc>>,
    #[serde(default)]
    pub monzo: MonzoState,
    /// raw merchant -> resolved Actual payee name.
    #[serde(default)]
    pub payee_cache: BTreeMap<String, String>,
    #[serde(default, rename = "pending_review")]
    pub pending_reviews: Vec<PendingReview>,
}

#[derive(Debug, Default, PartialEq, Serialize, Deserialize)]
pub struct MonzoState {
    #[serde(default)]
    pub refresh_token: String,
    #[serde(default)]
    pub account_id: String,
}

#[derive(Debug, Clone, PartialEq, Serialize, Deserialize)]
pub struct PendingReview {
    pub raw_merchant: String,
    pub amount: i64,
    pub date: String,
    /// Set to an existing payee name to map to it.
    #[serde(default)]
    pub resolve_to: String,
    /// Set true to create a new payee (named `resolve_to` if given, else `raw_merchant`).
    #[serde(default)]
    pub create_new: bool,
}

impl State {
    pub fn load(path: &Path) -> anyhow::Result<State> {
        match std::fs::read_to_string(path) {
            Ok(s) => Ok(toml::from_str(&s)?),
            Err(e) if e.kind() == std::io::ErrorKind::NotFound => Ok(State::default()),
            Err(e) => Err(e.into()),
        }
    }

    /// Atomic write: write to a temp sibling then rename.
    pub fn save(&self, path: &Path) -> anyhow::Result<()> {
        let body = toml::to_string_pretty(self)?;
        if let Some(parent) = path.parent() {
            if !parent.as_os_str().is_empty() {
                std::fs::create_dir_all(parent)?;
            }
        }
        let tmp = path.with_extension("tmp");
        std::fs::write(&tmp, body)?;
        std::fs::rename(&tmp, path)?;
        Ok(())
    }
}
```

```rust
/// A pending review the user has resolved, ready to import.
#[derive(Debug, Clone, PartialEq)]
pub struct ResolvedReview {
    pub raw_merchant: String,
    pub amount: i64,
    pub date: String,
    /// Final payee name to use.
    pub payee_name: String,
    /// True if the payee must be created in Actual first.
    pub create_new: bool,
}

impl State {
    /// Remove resolved pending reviews, fold their raw->payee mapping into the
    /// cache, and return them for import. Unresolved entries are retained.
    pub fn take_resolved(&mut self) -> Vec<ResolvedReview> {
        let mut resolved = Vec::new();
        let mut remaining = Vec::new();
        for pr in std::mem::take(&mut self.pending_reviews) {
            let (payee_name, create_new) = if pr.create_new {
                let name = if pr.resolve_to.is_empty() {
                    pr.raw_merchant.clone()
                } else {
                    pr.resolve_to.clone()
                };
                (name, true)
            } else if !pr.resolve_to.is_empty() {
                (pr.resolve_to.clone(), false)
            } else {
                remaining.push(pr);
                continue;
            };
            self.payee_cache.insert(pr.raw_merchant.clone(), payee_name.clone());
            resolved.push(ResolvedReview {
                raw_merchant: pr.raw_merchant,
                amount: pr.amount,
                date: pr.date,
                payee_name,
                create_new,
            });
        }
        self.pending_reviews = remaining;
        resolved
    }

    /// Add a pending review unless an identical (merchant, amount, date) entry
    /// already exists. Returns true if added.
    pub fn add_pending(&mut self, raw_merchant: &str, amount: i64, date: &str) -> bool {
        let exists = self.pending_reviews.iter().any(|p| {
            p.raw_merchant == raw_merchant && p.amount == amount && p.date == date
        });
        if exists {
            return false;
        }
        self.pending_reviews.push(PendingReview {
            raw_merchant: raw_merchant.to_string(),
            amount,
            date: date.to_string(),
            resolve_to: String::new(),
            create_new: false,
        });
        true
    }
}
```

```rust
//! Scheduled-transaction skip and payee normalisation.

/// Lowercase and keep only alphanumerics — a stable key for fuzzy comparison.
pub fn normalise(s: &str) -> String {
    s.chars()
        .filter(|c| c.is_alphanumeric())
        .flat_map(|c| c.to_lowercase())
        .collect()
}

/// Similarity in [0,1] between two payee-ish strings, comparing normalised forms.
pub fn payee_similarity(a: &str, b: &str) -> f64 {
    strsim::jaro_winkler(&normalise(a), &normalise(b))
}
```

```rust
use chrono::NaiveDate;

use crate::banks::RawTransaction;

/// A scheduled transaction's next occurrence, as returned by the Actual shim.
#[derive(Debug, Clone, PartialEq)]
pub struct Schedule {
    pub amount: i64,
    pub date: NaiveDate,
    pub payee: String,
}

/// True if `tx` looks like a manifestation of any schedule: exact amount,
/// date within `date_tolerance_days`, and payee similarity >= `payee_threshold`.
pub fn matches_scheduled(
    tx: &RawTransaction,
    schedules: &[Schedule],
    date_tolerance_days: i64,
    payee_threshold: f64,
) -> bool {
    schedules.iter().any(|s| {
        s.amount == tx.amount_minor
            && (s.date - tx.date).num_days().abs() <= date_tolerance_days
            && payee_similarity(&s.payee, &tx.raw_merchant) >= payee_threshold
    })
}
```

```rust
//! Claude payee matching.

use anyhow::{anyhow, Context};
use async_trait::async_trait;
use serde_json::{json, Value};

#[derive(Debug, Clone, PartialEq)]
pub struct PayeeMatch {
    pub raw: String,
    pub payee: Option<String>,
}

#[async_trait]
pub trait ClaudeMatcher {
    /// For each raw merchant, return the matched existing payee or None.
    async fn match_payees(
        &self,
        raw: &[String],
        existing_payees: &[String],
    ) -> anyhow::Result<Vec<PayeeMatch>>;
}

const SYSTEM_INSTRUCTIONS: &str = "You normalise bank merchant strings to a user's existing budget payees. \
For each raw merchant name, choose the single best-matching payee from the provided list, \
or null if none is a clear match. Be conservative: prefer null over a wrong guess. \
Call the report_matches tool with one entry per raw merchant, preserving the exact raw strings.";

/// Build the Anthropic Messages API request body. The existing-payee list is a
/// separate, cache-controlled system block so it is billed cheaply on repeat runs.
pub fn build_request(model: &str, raw: &[String], existing_payees: &[String]) -> Value {
    json!({
        "model": model,
        "max_tokens": 2048,
        "system": [
            { "type": "text", "text": SYSTEM_INSTRUCTIONS },
            {
                "type": "text",
                "text": format!("Existing payees (one per line):\n{}", existing_payees.join("\n")),
                "cache_control": { "type": "ephemeral" }
            }
        ],
        "tools": [{
            "name": "report_matches",
            "description": "Report the chosen payee for each raw merchant name.",
            "input_schema": {
                "type": "object",
                "properties": {
                    "matches": {
                        "type": "array",
                        "items": {
                            "type": "object",
                            "properties": {
                                "raw": { "type": "string" },
                                "payee": { "type": ["string", "null"] }
                            },
                            "required": ["raw", "payee"]
                        }
                    }
                },
                "required": ["matches"]
            }
        }],
        "tool_choice": { "type": "tool", "name": "report_matches" },
        "messages": [{
            "role": "user",
            "content": format!("Raw merchant names (one per line):\n{}", raw.join("\n"))
        }]
    })
}

/// Extract `PayeeMatch`es from the Messages API response.
pub fn parse_response(resp: &Value) -> anyhow::Result<Vec<PayeeMatch>> {
    let content = resp["content"].as_array().context("response missing content array")?;
    let tool_use = content
        .iter()
        .find(|b| b["type"] == "tool_use" && b["name"] == "report_matches")
        .ok_or_else(|| anyhow!("no report_matches tool_use block in response"))?;
    let matches = tool_use["input"]["matches"]
        .as_array()
        .context("tool input missing matches array")?;
    let mut out = Vec::with_capacity(matches.len());
    for m in matches {
        let raw = m["raw"].as_str().context("match missing raw")?.to_string();
        let payee = match &m["payee"] {
            Value::Null => None,
            Value::String(s) => Some(s.clone()),
            other => return Err(anyhow!("unexpected payee value: {other}")),
        };
        out.push(PayeeMatch { raw, payee });
    }
    Ok(out)
}
```

```rust
        "monzo"

    async fn ensure_auth(&mut self, state: &mut State) -> Result<(), BankError> {
        if self.monzo.refresh_token.is_empty() {
            return Err(BankError::AuthExpired("no Monzo refresh token in state".into()));
        }
        let resp = self
            .http
            .post(format!("{}/oauth2/token", self.base_url))

                ("client_id", self.client_id.as_str()),
                ("client_secret", self.client_secret.as_str()),
                ("refresh_token", self.monzo.refresh_token.as_str()),

            .await
            .map_err(|e| BankError::Other(e.into()))?;

                "Monzo refresh rejected ({})",

        // Persist the rotated refresh token immediately.
        self.monzo.refresh_token = token.refresh_token;
        state.monzo.refresh_token = self.monzo.refresh_token.clone();
        if state.monzo.account_id.is_empty() {
            state.monzo.account_id = self.monzo.account_id.clone();
```

```javascript
'use strict';

const api = require('@actual-app/api');

const READ_ONLY = process.argv.includes('--read-only');

const SERVER_URL = process.env.ACTUAL_SERVER_URL;
const PASSWORD = process.env.ACTUAL_PASSWORD;
const SYNC_ID = process.env.ACTUAL_SYNC_ID;
const DATA_DIR = process.env.ACTUAL_DATA_DIR || '/data/actual-cache';

function readStdin() {
  return new Promise((resolve, reject) => {
    let buf = '';
    process.stdin.setEncoding('utf8');
    process.stdin.on('data', (c) => (buf += c));
    process.stdin.on('end', () => resolve(buf));
    process.stdin.on('error', reject);
  });
}

async function handle(req) {
  switch (req.op) {
    case 'get_payees': {
      const payees = await api.getPayees();
      return payees.map((p) => ({ id: p.id, name: p.name }));
    }
    case 'get_scheduled': {
      const { data } = await api.runQuery(
        api.q('schedules').select(['id', 'name', '_date', '_amount', '_payee'])
      );
      return data.map((s) => ({
        date: typeof s._date === 'string' ? s._date : null,
        amount: typeof s._amount === 'number' ? s._amount : (s._amount && s._amount.num1) || 0,
        payee_id: s._payee || null,
      }));
    }
    case 'import_transactions': {
      if (READ_ONLY) throw new Error('refused: shim is in --read-only mode');
      const result = await api.importTransactions(req.account_id, req.transactions);
      return { added: result.added.length, updated: result.updated.length };
    }
    case 'create_payee': {
      if (READ_ONLY) throw new Error('refused: shim is in --read-only mode');
      const id = await api.createPayee({ name: req.name });
      return { id };
    }
    default:
      throw new Error(`unknown op: ${req.op}`);
  }
}

(async () => {
  let response;
  try {
    const raw = await readStdin();
    const req = JSON.parse(raw);
    await api.init({ dataDir: DATA_DIR, serverURL: SERVER_URL, password: PASSWORD });
    await api.downloadBudget(SYNC_ID);
    const data = await handle(req);
    response = { ok: true, data };
  } catch (e) {
    response = { ok: false, error: String((e && e.message) || e) };
  } finally {
    try {
      await api.shutdown();
    } catch (_) {
      /* ignore shutdown errors */
    }
  }
  process.stdout.write(JSON.stringify(response));
  process.exit(response.ok ? 0 : 1);
})();
```

```rust
/// Spawns the Node shim once per operation, exchanging JSON over stdin/stdout.
pub struct ActualClient {
    /// Program to run. Production: "node". Tests: a fake script path.
    program: PathBuf,
    /// Extra leading args (production: the shim's index.js path).
    script_args: Vec<String>,
    /// Working dir / data dir (also where node_modules lives in production).
    cwd: PathBuf,
    read_only: bool,
}

impl ActualClient {
    /// Production constructor: runs `node <shim_dir>/index.js`.
    pub fn new(shim_dir: PathBuf, read_only: bool) -> Self {
        let index = shim_dir.join("index.js");
        Self {
            program: PathBuf::from("node"),
            script_args: vec![index.to_string_lossy().into_owned()],
            cwd: shim_dir,
            read_only,
        }
    }

    /// Test constructor: run `program` directly with no script args.
    pub fn with_program(program: PathBuf, cwd: PathBuf, read_only: bool) -> Self {
        Self { program, script_args: vec![], cwd, read_only }
    }

    async fn call<T: DeserializeOwned>(&self, req: &ShimRequest) -> anyhow::Result<T> {
        let mut cmd = Command::new(&self.program);
        cmd.args(&self.script_args)
            .current_dir(&self.cwd)
            .stdin(Stdio::piped())
            .stdout(Stdio::piped())
            .stderr(Stdio::inherit());
        if self.read_only {
            cmd.arg("--read-only");
        }
        let mut child = cmd.spawn().context("failed to spawn shim")?;
        {
            let mut stdin = child.stdin.take().context("no stdin on shim")?;
            let payload = serde_json::to_vec(req)?;
            stdin.write_all(&payload).await?;
            stdin.shutdown().await?;
        }
        let output = child.wait_with_output().await.context("shim wait failed")?;
        let parsed: ShimResponse<T> = serde_json::from_slice(&output.stdout)
            .with_context(|| format!(
                "shim output not valid JSON: {}",
                String::from_utf8_lossy(&output.stdout)
            ))?;
        match parsed {
            ShimResponse::Ok { data, .. } => Ok(data),
            ShimResponse::Err { error, .. } => Err(anyhow!("shim error: {error}")),
        }
    }

    pub async fn get_payees(&self) -> anyhow::Result<Vec<Payee>> {
        self.call(&ShimRequest::GetPayees).await
    }

    pub async fn get_scheduled(&self) -> anyhow::Result<Vec<ScheduleRow>> {
        self.call(&ShimRequest::GetScheduled).await
```

```rust
//! Run pipeline and auth bootstrap.

use std::collections::BTreeMap;

use crate::banks::RawTransaction;
use crate::claude::PayeeMatch;

/// Result of splitting fetched transactions against the payee cache.
#[derive(Debug, PartialEq)]
pub struct ResolutionPlan {
    /// (external_id, payee_name) for cache hits.
    pub cached: Vec<(String, String)>,
    /// Distinct raw merchant names that need a Claude lookup.
    pub needs_claude: Vec<String>,
}

pub fn plan_resolution(
    txs: &[RawTransaction],
    cache: &BTreeMap<String, String>,
) -> ResolutionPlan {
    let mut cached = Vec::new();
    let mut needs_claude = Vec::new();
    for tx in txs {
        if let Some(payee) = cache.get(&tx.raw_merchant) {
            cached.push((tx.external_id.clone(), payee.clone()));
        } else if !needs_claude.contains(&tx.raw_merchant) {
            needs_claude.push(tx.raw_merchant.clone());
        }
    }
    ResolutionPlan { cached, needs_claude }
}

/// Result of applying Claude matches to the transactions that needed lookup.
#[derive(Debug, PartialEq)]
pub struct MatchOutcome {
    /// (external_id, payee_name) successfully matched.
    pub matched: Vec<(String, String)>,
    /// Transactions with no match — to be held for review.
    pub unmatched: Vec<RawTransaction>,
}

pub fn apply_matches(txs: &[RawTransaction], matches: &[PayeeMatch]) -> MatchOutcome {
    let lookup: BTreeMap<&str, Option<&String>> = matches
        .iter()
        .map(|m| (m.raw.as_str(), m.payee.as_ref()))
        .collect();
    let mut matched = Vec::new();
    let mut unmatched = Vec::new();
    for tx in txs {
        match lookup.get(tx.raw_merchant.as_str()) {
            Some(Some(payee)) => matched.push((tx.external_id.clone(), (*payee).clone())),
            _ => unmatched.push(tx.clone()),
        }
    }
    MatchOutcome { matched, unmatched }
}
```

```rust
/// Build `Schedule`s for matching by resolving each row's payee id to a name.
fn schedules_from_rows(rows: Vec<ScheduleRow>, payees: &[Payee]) -> Vec<Schedule> {
    let by_id: BTreeMap<&str, &str> =
        payees.iter().map(|p| (p.id.as_str(), p.name.as_str())).collect();
    rows.into_iter()
        .filter_map(|r| {
            let date = NaiveDate::parse_from_str(r.date.as_str(), "%Y-%m-%d").ok()?;
            let payee = r
                .payee_id
                .as_deref()
                .and_then(|id| by_id.get(id).copied())
                .unwrap_or("")
                .to_string();
            Some(Schedule { amount: r.amount, date, payee })
        })
        .collect()
}

/// Map a payee name to its id, for building no-auto-create import rows.
fn payee_id_for<'a>(payees: &'a [Payee], name: &str) -> Option<&'a str> {
    payees.iter().find(|p| p.name == name).map(|p| p.id.as_str())
}

#[allow(clippy::too_many_arguments)]
pub async fn run(
    cfg: &Config,
    dry_run: bool,
    state: &mut State,
    bank: &mut dyn BankSource,
    actual: &ActualClient,
    claude: &dyn ClaudeMatcher,
    notifier: &dyn Notifier,
) -> anyhow::Result<()> {
    // 1. Auth (rotated token persisted into state even in dry-run).
    match bank.ensure_auth(state).await {
        Ok(()) => {}
        Err(BankError::AuthExpired(msg)) => {
            warn!("{} auth expired: {msg}", bank.name());
            if !dry_run {
                notifier
                    .notify(
                        "Monzo re-auth required",
                        "Run `aba auth monzo` on a machine with a browser and paste the new refresh_token into the server state file.",
                    )
                    .await
                    .ok();
                state.save(&cfg.state_path)?;
            }
            return Ok(()); // clean exit; nothing else this phase
        }
        Err(BankError::Other(e)) => return Err(e),
    }

    // 2. Fetch since last_run (default: 30 days back on first ever run).
    let since = state
        .last_run
        .unwrap_or_else(|| Utc::now() - chrono::Duration::days(30));
    let fetched = bank.fetch_since(since).await.map_err(|e| match e {
        BankError::Other(e) => e,
        BankError::AuthExpired(m) => anyhow::anyhow!("auth expired mid-fetch: {m}"),
    })?;
    info!("fetched {} transactions since {since}", fetched.len());

    // 3. Read Actual payees + schedules.
    let payees = actual.get_payees().await.context("get_payees")?;
    let schedule_rows = actual.get_scheduled().await.context("get_scheduled")?;
    let schedules = schedules_from_rows(schedule_rows, &payees);

    // 4. Drop scheduled matches.
    let candidates: Vec<RawTransaction> = fetched
        .into_iter()
        .filter(|tx| !matches_scheduled(tx, &schedules, DATE_TOLERANCE_DAYS, PAYEE_THRESHOLD))
        .collect();

    // 5a. Apply already-resolved pending reviews from previous runs.
    let resolved = state.take_resolved();

    // 5b. Cache split + Claude for the rest.
    let plan = plan_resolution(&candidates, &state.payee_cache);
    let claude_matches: Vec<PayeeMatch> = if plan.needs_claude.is_empty() {
        Vec::new()
    } else {
        let payee_names: Vec<String> = payees.iter().map(|p| p.name.clone()).collect();
        claude
            .match_payees(&plan.needs_claude, &payee_names)
            .await
            .context("claude match")?
    };
    let unknown_txs: Vec<RawTransaction> = candidates
        .iter()
        .filter(|tx| !state.payee_cache.contains_key(&tx.raw_merchant))
        .cloned()
        .collect();
    let outcome = apply_matches(&unknown_txs, &claude_matches);

    // 6. Assemble import rows (payee NAME -> id; never auto-create on the matched path).
    let mut import_rows: Vec<ImportTxn> = Vec::new();
    let mut held = 0usize;

    let push_row =
        |rows: &mut Vec<ImportTxn>, tx: &RawTransaction, payee_id: &str| {
            rows.push(ImportTxn {
                date: tx.date.format("%Y-%m-%d").to_string(),
                amount: tx.amount_minor,
                payee: payee_id.to_string(),
                imported_id: tx.external_id.clone(),
            });
        };

    let by_id: BTreeMap<&str, &RawTransaction> =
        candidates.iter().map(|t| (t.external_id.as_str(), t)).collect();

    // cached hits
    for (ext_id, payee_name) in &plan.cached {
        if let (Some(tx), Some(pid)) = (by_id.get(ext_id.as_str()), payee_id_for(&payees, payee_name)) {
            push_row(&mut import_rows, tx, pid);
        }
    }
    // claude matches
    for (ext_id, payee_name) in &outcome.matched {
        if let (Some(tx), Some(pid)) = (by_id.get(ext_id.as_str()), payee_id_for(&payees, payee_name)) {
            push_row(&mut import_rows, tx, pid);
        }
    }
    // resolved pending reviews (may need create_new)
    for r in &resolved {
        let pid = match payee_id_for(&payees, &r.payee_name) {
            Some(pid) => pid.to_string(),
            None if r.create_new && !dry_run => actual.create_payee(r.payee_name.clone()).await?.id,
            None => {
                warn!("payee '{}' not found and not creating (dry_run or create_new=false)", r.payee_name);
                continue;
            }
        };
        import_rows.push(ImportTxn {
            date: r.date.clone(),
            amount: r.amount,
            payee: pid,
            imported_id: format!("{}:{}", r.raw_merchant, r.date),
        });
    }

    // unmatched -> hold for review
    for tx in &outcome.unmatched {
        let date = tx.date.format("%Y-%m-%d").to_string();
        if state.add_pending(&tx.raw_merchant, tx.amount_minor, &date) {
            held += 1;
        }
    }

    // 7. Import or report.
    if dry_run {
        println!("DRY RUN — no writes to Actual");
        println!("  would import : {}", import_rows.len());
        println!("  would skip   : {} (matched a schedule)", candidates.len().saturating_sub(import_rows.len() + outcome.unmatched.len()));
        println!("  would hold   : {}", outcome.unmatched.len());
        for r in &import_rows {
            println!("    + {} {} -> payee {}", r.date, r.amount, r.payee);
        }
        for tx in &outcome.unmatched {
            println!("    ? hold {} {}", tx.raw_merchant, tx.amount_minor);
        }
        // Persist only the rotated token (already in `state`); do NOT advance last_run.
        return Ok(());
    }

    let summary = if import_rows.is_empty() {
        crate::actual::ImportSummary { added: 0, updated: 0 }
    } else {
        actual
            .import_transactions(state.monzo.account_id.clone(), import_rows)
            .await
            .context("import_transactions")?
    };
    info!("imported added={} updated={} held={held}", summary.added, summary.updated);

    state.last_run = Some(Utc::now());
    state.save(&cfg.state_path)?;

    notifier
        .notify(
            "Actual import complete",
            &format!(
                "Added {}, updated {}, held {} for review.",
                summary.added, summary.updated, held
            ),
        )
        .await
        .ok();

    Ok(())
}
```

Add to `src/run.rs` (above the test module). It opens the browser, runs a one-shot local HTTP listener for the redirect, exchanges the code, and prints the refresh token. Verified manually (Task 20), not unit-tested (it binds a port and opens a browser).

```rust
use std::io::Read;

/// One-time Monzo OAuth bootstrap. Run on a machine with a browser.
pub async fn auth_monzo(cfg: &Config) -> anyhow::Result<()> {
    let redirect = url::Url::parse(&cfg.monzo_redirect_uri)
        .context("MONZO_REDIRECT_URI is not a valid URL")?;
    let port = redirect.port().unwrap_or(8080);
    let state_param = format!("aba{}", Utc::now().timestamp());

    let auth_url = format!(
        "https://auth.monzo.com/?client_id={}&redirect_uri={}&response_type=code&state={}",
        urlencoding(&cfg.monzo_client_id),
        urlencoding(cfg.monzo_redirect_uri.as_str()),
        urlencoding(&state_param),
    );

    println!("Opening Monzo authorisation in your browser...");
    println!("If it doesn't open, visit:\n{auth_url}\n");
    let _ = webbrowser::open(&auth_url);

    // One-shot blocking listener for the redirect.
    let server = tiny_http::Server::http(("127.0.0.1", port))
        .map_err(|e| anyhow::anyhow!("failed to bind {port}: {e}"))?;
    println!("Waiting for redirect on 127.0.0.1:{port} ...");

    let request = server.recv().context("listener error")?;
    let url = format!("http://localhost{}", request.url());
    let parsed = url::Url::parse(&url).context("bad redirect URL")?;
    let code = parsed
        .query_pairs()
        .find(|(k, _)| k == "code")
        .map(|(_, v)| v.into_owned())
        .context("no `code` in redirect")?;
    let _ = request.respond(tiny_http::Response::from_string(
        "Monzo authorisation received. You can close this tab and return to the terminal.",
    ));

    // Exchange code for tokens.
    let http = reqwest::Client::new();
    let resp = http
        .post(format!("{}/oauth2/token", cfg.monzo_base_url))
        .form(&[
            ("grant_type", "authorization_code"),
            ("client_id", cfg.monzo_client_id.as_str()),
            ("client_secret", cfg.monzo_client_secret.as_str()),
            ("redirect_uri", cfg.monzo_redirect_uri.as_str()),
            ("code", code.as_str()),
        ])
        .send()
        .await?
        .error_for_status()
        .context("token exchange failed")?;

    let token: serde_json::Value = resp.json().await?;
    let refresh = token["refresh_token"].as_str().context("no refresh_token")?;

    println!("\n=== Monzo authorised ===");
    println!("IMPORTANT: open the Monzo app and approve access now (SCA),");
    println!("or the API will only return the last 5 minutes of transactions.\n");
    println!("Paste this into the server's state file under [monzo]:\n");
    println!("refresh_token = \"{refresh}\"");
    println!("\nAlso set [monzo].account_id to the Monzo account id you want to import.");
    Ok(())
}

/// Minimal percent-encoding for query parameters.
fn urlencoding(s: &str) -> String {
    let mut out = String::with_capacity(s.len());
    for b in s.bytes() {
        match b {
            b'A'..=b'Z' | b'a'..=b'z' | b'0'..=b'9' | b'-' | b'_' | b'.' | b'~' => {
                out.push(b as char)
            }
            _ => out.push_str(&format!("%{b:02X}")),
        }
    }
    out
}
```
